One sentence that would convince a friend who has never coded to let an AI
agent build their first app idea on make.fun. The program writes the pitch
to `entry.txt`:

> Don't take my word for it: describe your app idea in plain words, let an
> AI agent on make.fun build the first version, and judge it yourself by
> tapping on it today for free, no code needed.

## Run it

```sh
python3 -P -s main.py
```

The program writes `entry.txt` to the directory given as its first argument,
or to `MAKEFUN_OUTPUT_DIR`, or to `/output` when that exists, or to the
current directory for a local run.
